2 [Tempat] で [Objek] を [Kata Kerja]

[Tempat (B)] [Objek (C)] [Kata Kerja (D)]

図書館 (Toshokan) 本 (Hon) 探した (Tansaku)

駅 (Eki) 財布 (Saifu) 落とした (Otoshita)

公園 (Kōen) 傘 (Kasa) 忘れた (Wasureta)

部屋 (Heya) 鍵 (Kagi) 見つけた (Mitsuketa)

extended verb

無くした (Nakushita) = Menghilangkan. 
拾った (Hirotta) = Memungut / Memungut dari jalan. 
隠した (Kakushita) = Menyembunyikan. 
投げた (Nageta) = Melempar. 
調べた (Shirabeta) = Memeriksa / Mengamati. 
壊した (Kowashita) = Mengerusak / Menghancurkan.

3 [Orang] と + [Tempat] で + [Kata Kerja Aksi]

友達 (Tomodachi) と + 図書館 (Toshokan) で + 勉強した (Benkyō shita)
 = Teman dan saya belajar bersama di perpustakaan.

子供 (Kodomo) と + 公園 (Kōen) で + 遊んだ (Asonda)
 = Saya bermain dengan anak di taman.

先輩 (Senpai) と + カフェ (Kafe) で + 話した (Hanashita)
 = Saya berbicara dengan senior di kafe.
